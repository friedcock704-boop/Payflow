    Queue - FIFO

    A Queue follows the First In, First Out principle. The transaction that enters the system first is processed first.

    Operations: Enqueue, Dequeue, Peek — O(1)

    Linear Search

    Linear Search checks transactions one by one until the required transaction is found.

    Best: O(1) · Worst: O(n)

    Bubble Sort

    Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

    Best: O(n) · Average: O(n²) · Worst: O(n²)

    Time Complexity

    Time complexity describes how the running time of an algorithm changes as the input size increases.

    O(1)   Constant
O(n)   Linear
O(n²)  Quadratic
